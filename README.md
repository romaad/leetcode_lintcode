## Overview
This repository serves as a personal log and reference guide for Data Structures and Algorithms (DSA) topics, focusing on:
* **Time and Space Complexity:** Optimal approaches with asymptotic analysis.
* **Multiple Approaches:** Comparing brute-force, intermediate, and optimal solutions where applicable.
* **Core Topics:** Dynamic Programming, Graphs, Trees, Two Pointers, Binary Search, Sliding Window, and more.
All solutions are accepted by the respective platform.
